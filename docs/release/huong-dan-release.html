Dùng bảng dưới. Không dán secret vào chat, Git, build args hoặc VITE_*. Khóa v1 phải giữ đúng giá trị đã sao lưu.

Biến runtime Điền gì

Biết cách rollback

Bạn tự làm trên web

Có đường quay lại khi bản mới lỗi.

Phiếu thao tác / cấu hình · không chạy như lệnh shell 
Trước migration: backup → kiểm commit → deploy → smoke → ghi SHA/image.
Khi lỗi: kiểm schema tương thích → chọn SHA/image tốt → deploy → smoke.

Bước dự phòng: tích khi đã đọc và hiểu; không cần rollback thử DB thật. Chỉ rollback app nếu schema tương thích. Không sửa migration đã áp dụng hoặc xóa Flyway history.

Nếu lỗi: Schema không tương thích: dừng; restore DB cần PO quyết mức mất dữ liệu trước thao tác ghi đè.

Nguồn: runbook §6

Đừng làm

  • Bỏ verify TLS.
  • Đặt hops lớn hơn số proxy thực tế.
  • Đổi pepper nhưng giữ nhãn v1.
  • Nâng gói trả phí để chữa thiếu RAM khi chưa được PO duyệt.
  • Cron ping Neon hoặc tạo Render Postgres Free cho dữ liệu cần giữ.
  • Commit secret/.env hoặc đưa secret vào chat/VITE_*.
  • Sửa migration đã áp dụng hoặc xóa Flyway history.
  • Mở cho người lạ khi các gate vẫn mở.
Nguồn: runbook §2–7; decisions.md §3b.

Từ điển bỏ túi

Flyway
Chạy các bản thay đổi schema theo thứ tự.
Pepper
Khóa bí mật server dùng HMAC mã khôi phục; khác mật khẩu DB.
Readiness
Tín hiệu app sẵn nhận traffic; probe Free không truy vấn DB.
Proxy hop
Một proxy trung gian đáng tin giữa người gọi và app.
Neon
Nơi giữ PostgreSQL demo.
Render
Nơi chạy Docker của demo.
Docker image
Gói web, ứng dụng và runtime đã build.
Smoke test
Thử nhanh các luồng trọng yếu sau deploy.
Cold start
Lần đánh thức dịch vụ đang ngủ; cần kiểm hành vi thật.
