## Trích dẫn nguồn chính thức (truy cập 04/11/2026)

- Unsplash API docs: “we require the image URLs returned by the API to be directly used or embedded” — https://unsplash.com/documentation
- Unsplash API Guidelines: “All API uses must use the hotlinked image URLs” và quy tắc credit/download — https://help.unsplash.com/en/articles/2511245-unsplash-api-guidelines
- Unsplash API Terms (hotlink, dữ liệu ảnh, privacy): https://unsplash.com/api-terms
- Pexels API documentation (prominent link, credit, hạn mức 200/giờ và 20.000/tháng, key): https://www.pexels.com/api/documentation/
- Pexels giới hạn nâng cao tạm dừng, điều kiện attribution (cập nhật 02/11/2026): https://help.pexels.com/hc/en-us/articles/900005852323-How-do-I-get-unlimited-requests
- TikTok Embed Videos (oEmbed, creator attribution; khuyến cáo migrate sang Embed Player): https://developers.tiktok.com/docs/en/embed-videos
- TikTok Embed Player (iframe): https://developers.tiktok.com/docs/en/embed-player
- Pinterest Add-ons (script pinit.js): https://developers.pinterest.com/docs/web-features/add-ons-overview/
- Pinterest Developer Terms và Guidelines (review, consent/cookie, AI, không lưu dữ liệu, link nguồn): https://developers.pinterest.com/terms/
- Openverse throttle/authentication: https://docs.openverse.org/api/reference/authentication_and_throttling.html
- Openverse nội dung và cảnh báo phải xác minh giấy phép: https://docs.openverse.org/api/reference/made_with_ov.html
- Openverse API Terms (rate limits, attribution, không scraping, trách nhiệm xác minh license): https://docs.openverse.org/_preview/2205/terms_of_service.html

## Điểm cần PO quyết định

1. Với ảnh tĩnh sản phẩm, ưu tiên Pexels (API credits rõ) hoặc Openverse (mỗi ảnh tự xác minh license); Unsplash dùng được nhưng đòi hỏi hotlink/duyệt production và attribution đặc tả.
2. Ảnh địa điểm cần biên tập viên xác minh rằng ảnh thực sự mô tả địa điểm; nguồn ảnh tự nó không chứng minh điều đó.
3. Dành mục “Từ cộng đồng” cho liên kết/embed tùy chọn, không biến ảnh/video MXH thành asset Wander; triển khai có privacy review và lazy-load.
4. Trước khi production, xác minh lại các mục **UNVERIFIED**, nhất là quyền/API hiện hành của Instagram, quota Openverse/Pinterest, cache và consent/cookie theo khu vực người dùng.
